# 스택·큐·덱: 어떤 순서로 꺼낼까?

이 문서는 선택 과제인 개념 설명입니다. 별도의 스택·큐·덱 명령이나 Pub/Sub를 구현했다는 뜻은 아닙니다.

## 스택: 접시 쌓기

접시를 위에 쌓으면 가장 나중에 올린 접시를 먼저 꺼냅니다. 이 순서를 **LIFO**, Last In First Out이라고 합니다.

넣기는 `push`, 꺼내기는 `pop`이라고 부릅니다. a, b, c 순서로 넣으면 c, b, a 순서로 나옵니다. 되돌리기 기능에서 가장 최근 작업부터 취소하는 모습을 떠올릴 수 있습니다.

이 프로젝트의 연결 리스트에서 `insert_front`로 넣고 `remove_front`로 꺼내면 같은 동작을 만들 수 있습니다. 두 연산 모두 O(1)입니다.

## 큐: 매표소 대기 줄

먼저 온 사람이 먼저 나갑니다. 이 순서를 **FIFO**, First In First Out이라고 합니다.

넣기는 `enqueue`, 꺼내기는 `dequeue`라고 부릅니다. a, b, c 순서로 넣으면 a, b, c 순서로 나옵니다. 접수한 작업을 순서대로 처리하는 상황에 어울립니다.

연결 리스트의 `insert_back`으로 뒤에 넣고 `remove_front`로 앞에서 꺼내면 큐가 됩니다. 둘 다 O(1)입니다. 일반 배열의 맨 앞을 지우고 나머지를 모두 당기는 방식과 비용이 다릅니다.

## 덱: 양쪽으로 출입하는 줄

**Deque**는 Double-Ended Queue의 줄임말입니다. 앞뒤 양쪽에 넣고 양쪽에서 꺼낼 수 있습니다. 스택과 큐의 동작을 모두 표현할 수 있습니다.

이 프로젝트의 이중 연결 리스트가 제공하는 insert_front, insert_back, remove_front, remove_back이 네 가지 기본 동작입니다.

## LRU와의 관계

LRU는 맨 앞과 맨 뒤만 다루는 것으로 끝나지 않습니다. 중간에 있는 키를 GET할 때 그 노드를 맨 앞으로 이동해야 합니다. 따라서 단순 큐보다 “노드 위치를 알고 중간 삭제가 가능한 이중 연결 리스트 + 위치를 찾아주는 해시맵”의 조합이 적합합니다.

힙도 push/pop이라는 이름을 쓰지만 스택처럼 최근 원소를 꺼내지 않습니다. 이 프로젝트의 최소 힙은 만료 시각이 가장 이른 원소를 꺼냅니다. 함수 이름만 보고 순서를 판단하지 말고 자료구조의 규칙을 확인하세요.

## 확인 문제

a, b, c를 차례로 넣었습니다. 스택에서 두 번 꺼내면 무엇이 나오나요? 큐에서는 무엇이 나오나요?

정답: 스택은 c, b이고 큐는 a, b입니다. LRU에서는 중간에 어떤 키를 조회했는지까지 알아야 제거 순서를 판단할 수 있습니다.
